# Internal versions

Files in this folder are not shown on the repository front page. I keep them for specific situations, not for general sending.

| File | What it is | When I use it |
| --- | --- | --- |
| `Idris-Ardi-Resume-WFO-Jakarta-ID.md` | Same resume in Indonesian, for on-site roles in Jakarta Greater Area | When the recruiter or the company works in Indonesian |
| `Idris-Ardi-Resume.md` | Previous default version, English | Kept for reference and for links that still point here |
| `Idris-Ardi-Resume.pdf` | PDF of the previous default version | Same as above |

The two files I send by default are in the repository root:

- `Idris-Ardi-Resume-WFO-Jakarta-EN.md` and `.pdf`
- `Idris-Ardi-Resume-Remote-EN.md` and `.pdf`
